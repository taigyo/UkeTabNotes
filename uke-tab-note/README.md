# ウクレレ Tab ノート（公開用パッケージ）

```
uke-tab-note/
├─ public/            ← 公開するファイル（これがサイトの中身）
│   ├─ index.html     アプリ本体
│   ├─ sw.js          オフライン用（Service Worker）
│   ├─ manifest.webmanifest  ホーム画面に追加するための情報
│   ├─ _headers       キャッシュの設定
│   └─ icons/         アプリのアイコン
├─ wrangler.jsonc     Cloudflare Workers で公開するときの設定
└─ README.md
```

## 公開の流れ（GitHub → Cloudflare）
1. このフォルダごと GitHub のリポジトリに入れる（private でも可）。
2. Cloudflare ダッシュボードでリポジトリを連携する。
   - **Workers（静的アセット）で公開する場合**：`wrangler.jsonc` がそのまま使えます。ビルドコマンドは不要です。
   - **Pages で公開する場合**：ビルドコマンドは空、出力ディレクトリは `public` にします。`wrangler.jsonc` は使いません。
3. 以後は `main` に push するたびに自動で更新されます。
4. 自分用なら、Cloudflare Access などでログイン必須にしておくと安全です。

※ 手順や画面は変わることがあるので、迷ったら Cloudflare の公式ドキュメントを優先してください。

## スマホで使う
- iPhone（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：メニュー →「ホーム画面に追加」または「アプリをインストール」
- 公開した URL を **一度開いておく** と、次回から電波がなくても開けます（画面下に「オフライン利用：準備できています」と出ます）。
- **同じ URL だけを使う** こと。URL（ドメイン）が変わると、保存した譜面は別扱いになり見えなくなります。

## 画面を消さない機能
- 演奏画面を開いている間、画面が消えないようにします（設定ボタンでオン/オフ）。
- iPhone の **ホーム画面から開くアプリ** では、iOS 18.4 より前だと動きません。その場合は Safari のタブで開くか、端末の「自動ロック」を長めにしてください。
- 端末の省電力モードなどで、拒否されることもあります。

## 譜面のバックアップと移動
- 譜面はそれぞれの端末のブラウザ内に保存されます。**PCの譜面は、そのままではスマホに出ません。**
- トップ画面の「バックアップ」→「ファイルに保存」（またはコピー）でPC側から書き出し、スマホ側の同じ画面の「読み込み」で取り込みます。
- 読み込みは「追加」です。同じ譜面を何度も読み込むと重複します。
- 「最後にバックアップした日」がトップ画面に出ます。書き出したファイルは、リポジトリや Drive などに置いておくと安心です。
- Safari はサイトを7日使わないと保存データが消えることがあります。大事な譜面は必ずバックアップしてください。

## 更新したとき
- `public/index.html` を差し替えて push すると反映されます。
- 次に開いたとき、裏で最新版を取得し、見つかると「新しいバージョンがあります」と出ます。「再読み込み」で切り替わります。
